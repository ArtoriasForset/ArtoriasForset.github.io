Smart Factory Edge MES

工业设备监控、边缘控制、环境监测与Agent平台

一、项目定位

规划蓝图

定位：
  • 轻量MES
  • 轻量SCADA
  • 边缘控制器（Soft PLC）
  • 未来Agent平台

二、总体架构

设备层 ↓ ZLAN6808 / PLC / 远程IO ↓ Modbus TCP ↓ Edge Runtime (Worker Service) ↓ OPC UA Server ↓ SQL Server ↓ ASP.NET Blazor ↓ Agent

三、系统组成

1. Edge Runtime（核心）

项目： IndustrialMonitor.EdgeRuntime

职责：
  • Modbus TCP采集
  • 温湿度采集
  • 计数采集
  • 良率计算
  • 告警检测
  • 规则执行
  • DO控制
  • OPC UA Server

本质： 边缘控制器（Soft PLC）

2. Web MES

项目： IndustrialMonitor.Web

职责：
  • 实时监控
  • 历史曲线
  • 统计分析
  • 规则配置
  • 设备管理
  • 告警管理
  • Agent入口

3. Agent

项目： IndustrialMonitor.Agent

职责：
  • 异常分析
  • 日报生成
  • 告警总结
  • 规则建议
  • 设备控制建议

四、业务场景

场景一：产品计数

来源：
DI输入 光电传感器 经过一个产品 计数+1
统计：
  • 实时产量
  • 今日产量
  • 班次产量
  • 累计产量

场景二：良品率统计

来源：
DI1 = 总产品 DI2 = 良品产品
计算：
总数 = 1000 良品 = 980 不良 = 20 良率 = 980 / 1000 = 98%
展示：
  • 实时良率
  • 小时良率趋势
  • 日报
  • 月报

场景三：环境监测

来源：
AI1 = 温度 AI2 = 湿度 AI3 = CO2 AI4 = 光照
展示：
  • 实时温度
  • 实时湿度
  • 实时CO2
  • 实时光照

场景四：设备控制

设备：
  • 空调
  • 风机
  • 加湿器
  • 报警器
DO映射：
DO1 = 空调 DO2 = 风机 DO3 = 加湿器 DO4 = 报警器

五、规则引擎

高温开启空调

IF 温度 > 28 THEN 启动空调

低温关闭空调

IF 温度 < 25 THEN 关闭空调

低湿开启加湿器

IF 湿度 < 70 THEN 开启加湿器

高湿关闭加湿器

IF 湿度 > 90 THEN 关闭加湿器
说明：

所有阈值必须可配置，不允许写死在代码中。

八、Worker周期扫描流程

每1秒执行： 1.读取AI 2.读取DI 3.读取计数器 4.更新实时表 5.保存历史表 6.判断告警 7.执行规则 8.控制DO 9.更新设备状态

九、OPC UA建模

Factory ├ Temperature ├ Humidity ├ CO2 ├ ProductCount ├ YieldRate ├ AirConditioner ├ Fan ├ Humidifier └ AlarmStatus
MES、Agent、视觉系统全部使用这些业务语义节点。
