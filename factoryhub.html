01 / THE PLATFORM

从设备数据，到
可理解的现场系统。

工业现场由不同品牌、协议和生命周期的设备组成。FactoryHub 以领域模型为中心，把实时状态、业务任务、告警事件与执行记录关联起来，为数字化管理和 Agent 推理提供可靠上下文。

01 — MODEL

统一的领域模型

以 DDD 组织 Device、Tag、Alarm、Task 与 Command，让设备状态和业务语义成为系统的一等概念。

02 — CONNECT

开放的工业连接

通过 OPC UA、MQTT、Modbus 等协议连接 PLC、远程 IO、视觉服务和智能设备，降低系统之间的集成壁垒。

03 — INTELLIGENCE

有上下文的智能

让 Agent 基于设备关系、任务进度、报警历史与运行约束分析问题，而不是只对孤立数值作出反应。

02 / SYSTEM ARCHITECTURE

每一层各司其职。
系统协同，而非互相替代。

FactoryHub 不试图用一个 AI 模型替代整个工业控制栈。它将确定性控制、环境感知、业务编排和智能决策分离，通过清晰的接口协同工作。

03 / ENGINEERING PRINCIPLES

控制自治。
系统协同。智能决策。

清晰的责任边界，让传统自动化的可靠性与 AI 的适应性可以共同发挥作用。

01 / SENSE

感知现场

采集设备遥测、告警、视觉结果和运行事件，形成可追溯的状态事实。

02 / CONTROL

安全执行

由 PLC 与本地控制逻辑处理确定性动作、联锁与设备状态转换。

03 / COORDINATE

组织业务

FactoryHub 管理任务、资源、流程和跨设备协作，保留清晰的执行记录。

04 / DECIDE

辅助决策

Agent 解释复杂情况、比较可能方案，并在明确权限范围内提供决策支持。

04 / DESIGNED TO GROW

从一个单元，
逐步扩展到一座工厂。

平台以可组合的领域能力为基础，先解决可验证的设备连接与业务问题，再逐步扩展智能分析和跨单元协作。

设备与数据

设备注册、Tag 建模、遥测采集、状态追踪与连接健康管理。

任务与流程

将设备动作放入有上下文的业务任务中，跟踪任务生命周期与执行结果。

告警与可观测性

统一查看告警、事件、状态变化和命令历史，帮助定位问题并复盘过程。

Agent 与策略优化

基于授权数据提供异常解释、趋势总结、方案建议和运营决策辅助。

THE CORE IDEA
让控制系统可靠地执行，让业务系统理解全局，让 AI 帮助人们看见更多可能。

FactoryHub 的目标不是让 AI 无条件接管机器，而是建立一个能被理解、能被协调、能被审计，并能随着需求逐步演进的物理世界软件系统。
