Edge Computing Layer

边缘计算层

The core runtime is implemented using C# Worker Service. It continuously communicates with industrial devices through Modbus TCP, collects telemetry, executes discrete control commands, handles alarms, maintains connections and performs protocol conversion. This layer acts as the industrial operating runtime.

核心运行时采用 C# Worker Service 实现。 持续通过 Modbus TCP 与现场设备通讯，完成数据采集、离散控制、 报警监控、连接管理以及协议转换。 该层相当于工业现场的软件运行时。

Business systems

Data Platform

数据平台

SQL Server provides persistent storage for process values, production records, alarms, traceability information, equipment status and operational history. The database becomes the foundation of industrial analytics, MES workflows and AI-driven applications.

SQL Server 用于存储工艺数据、生产记录、报警信息、 追溯数据、设备状态以及历史运行数据。 数据库是 MES、统计分析以及 AI 应用的核心基础设施。

Business Systems

业务系统

A complete ASP.NET Core + SQL Server stack is used to build MES, equipment management, production tracking, quality management, dashboards and reporting systems. The architecture supports both edge deployment and cloud deployment.

采用 ASP.NET Core + SQL Server 技术栈开发 MES、设备管理、生产追踪、质量管理、 数据看板与报表系统。 同时支持边缘部署与云端部署。

Agent Architecture

Agent 架构

Microsoft Agent Framework serves as the orchestration layer. Agents can access industrial data, invoke tools, query business systems, call APIs, and interact with MQTT, OPC UA and Modbus-based devices. The objective is not replacing PLC logic, but augmenting human decision-making.

Microsoft Agent Framework 作为智能编排层。 Agent 可以访问工业数据、调用工具、 查询业务系统、调用 API， 并与 MQTT、OPC UA、Modbus 设备进行交互。 目标不是替代 PLC，而是增强人的决策能力。
